# Criterios de aceptación

El proyecto se considera correcto si:

1. El navbar y el sidebar aparecen en **todas** las páginas autenticadas.
2. El sidebar colapsa y expande sin perder funcionalidad.
3. El nombre del usuario logueado y el botón de cerrar sesión están en el navbar.
4. La paleta de verdes se aplica consistentemente en toda la interfaz.
5. Los títulos usan la escala tipográfica definida.
6. Las rutas del CRUD funcionan con React Router.
7. El código está organizado según la estructura de carpetas definida.
